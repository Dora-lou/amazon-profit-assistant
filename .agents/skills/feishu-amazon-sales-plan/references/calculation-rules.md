# 计算规则与校验边界

本文件供执行销售计划时查阅。具体单元格地址由当前飞书表格布局决定，不能照搬其他产品的行列号。优先延续原表中有效的公式和字段。

## 1. 数据键和快照

- 用站点、ASIN、MSKU/SKU、FNSKU 识别明细。多条库存记录先确认互不重叠，再汇总到计划 SKU；不同 MSKU 不凭名称相似就合并。
- 记录库存和实际销量的统计日期、时区、来源。月实际销量须按同一个站点、SKU 和自然月匹配。
- 按用户最近明确的口径，规划库存核对 `FBA可售 + FBA待调仓 + FBA入库中 + FBA实际在途 + FBA计划入库 + AWD可用 + AWD标发在途`。这些 FBA 列可能记录同一批货从计划、运输、接收至可售的状态变化；检查来源定义并把已知重叠风险说明。用户明确要求某 SKU 只计其中一个状态（如只计FBA计划入库）时，按 SKU 级例外取数并备注。不得因怀疑重叠就暗中修改用户指定口径，也不得无说明地把同一批货重复加总。
- 在途或待调仓的到货时间与可售状态分别展示，不能暗示它们现在已经可售。
- **按月份检查到货能力**：当前库存快照与有日期的未来到货批次分开保存。月末可承接库存=纳入规划的当前库存+截至该月末预计到货批次−该快照之后已排计划销量。11月中旬到货不能支持10月销量；12月到货不能分配给11月或更早月份。用户指定某SKU某月才可开卖时，更早月份销量必须为0。
- 保留领星原始来源字段，不因去重而改写原值。若同一批次同时出现在AWD标发在途、FBA实际在途、FBA入库中等字段，按批次/数量/日期辨认重复，仅在规划总库存/到货批次汇总中计一次，并注明依据。无法辨明则标「重复待核实」，不可全字段直接相加后声称库存已核准。
- 用户提供的未来到货数量/日期与领星当前快照分列，注明来源及是否已计入快照。若已计入，不得再次叠加。用户设定单品例外时逐SKU执行并备注。

## 2. 计划量、实际量与库存

设 `P` 为规划期 SKU 计划，`A` 为计划中已发生且与 `P` 同站点、同 SKU、同自然月/期间口径的实际销量，`S` 为库存数。先确认 `S` 是季初/销量发生前库存，还是已扣过 `A` 的当前库存；不能只看列名推断。

- 若 `S` 是当前快照库存，且 `P` 是包含快照日前实际销量 `A` 的累计目标，未来待售量 `=MAX(P-A,0)`，期末库存 `=S-未来待售量`。此时将累计目标 `P` 直接与当前库存 `S` 比较可能误判；应检查未来待售量是否超过 `S`。若 `A>P`，明确显示「实际已超计划」，不能因 `MAX` 而掩盖。
- 若 `P` 是快照日之后的未来计划量，未来待售量 `=P`，期末库存 `=S-P`；历史销量不再从 `S` 中扣除。
- 若 `S` 是季初/销量发生前库存，且 `P` 是整季累计目标（包括已发生的 `A`），季末余额按 `S-P` 计算；不能再把 `A` 加/减第二次。
- 若用户要求累计计划量不能大于某库存数，但这个库存数其实是快照日剩余库存、且计划中包含已售量，两种约束可能冲突。不要擅自改库存或实际销量：保留原始值，注明应比较的口径，并把冲突 SKU 标为待核对。
- 若实际销量大于当前库存快照、实际销量超过计划、库存与销量日期/时区不一致，单独标出异常和来源日期。不要靠 `MAX(...,0)`、按 SKU 差额抵消或改写历史数据把异常藏起来。
- 若实际销量和库存快照的 SKU、时间或库存口径无法对齐，标明待核对，不展示未经核实的期末库存为准确值。
- 库存消化率须明确分母。以当前快照为基准时，可用 `=IFERROR(未来待售量/S,0)`；不能把计划期内已经完成的销量再次算作当前库存消化。
- `S-未来待售量<0` 时红色提示，并重新检查月计划。单 SKU 不能靠其他 SKU 的库存抵消超卖。

所有名为「差值」的销售计划字段统一采用 `实际销量-月计划销量`，保留正负值；例如实际销量比计划少10件，差值必须显示 `-10`。折扣区也不能把正的待完成数量冒称为差值。折扣利润所需的待完成件数单独在利润公式中使用 `MAX(-差值,0)`（等价于 `MAX(月计划销量-同月实际销量,0)`）。这样实际超计划时差值显示正数，但折扣情景的待完成件数为0。差值不能和库存余额混为一谈。

> **优先级说明：** 本参考中的旧版「月销量手输、比例仅核对」默认规则已被主 Skill 的「固定模板锁定（最高优先级）」取代。标准新建/重做计划必须是比例驱动：可编辑比例→月销量公式→月合计与规划期待售总计划公式。仅当用户在本次任务明确要求直接手输月销量时，才可临时启用手输模式；不得同时启用两种驱动，也不得把手输模式保留为新默认。
## 2A. 标准模式：比例驱动的固定模板

主 Skill 的「固定模板锁定」和「月度比例与销量公式」是标准要求。本节只补充边界规则，不得回退到旧版手输销量为默认。

- 可编辑输入为规划月目标比例和SKU销售比例；月总目标、SKU月销量、日均、规划期待售总计划、月合计及全期合计都是公式输出。比例变化必须沿公式链改变计划量。单元格不能同时是输入和公式输出。
- 月目标比例按用户给定的库存消化目标计算规划总量；各月计划目标按规划期总计划量乘该月比例。每月SKU比例分别分配该月目标。SKU整数化后与目标不平时显示差额并说明需调整的SKU/比例，不能静态补差、强压末行或忽略超库存。
- 用户想改单SKU某月数量时，调整对应的SKU月销售比例；更新后该SKU月销量、日均、该月汇总、期内待售总计划、销售额、加权均价、广告花费、利润率和预计库存均联动。不可将公式格改为手填值，也不能暗改无关月份。
- 只有用户本次明确要求直接编辑月销量时，才可临时切换为手动数量模式；此时比例只能作为公式核对结果。应在交付中指出当前模式，不可让它变成后续新表的默认。
- 任何整数分配方法都要逐SKU校验库存和月度比例。不可行时显示未分配目标和具体超限，不可跨SKU抵消或伪装通过。
- 验证时临时更改月目标比例、SKU比例、售价、TACOS、实际销量；检查公式输出与依赖变化，再恢复原值。回读公式和值，检查无循环、引用错误和负库存。
## 2B. 例外模式：已结束月份与完全自动滚动追补

适用条件：规划期内有已结束月份实际销量，或用户明确要求按截至日期的实际进度提前结转，且需把未完成量纳入后续月份计划。优先在原「销售计划」sheet 的SKU明细中实现，不另建专用分摊算法表，也不增加独立比例工作表；用户要求把复盘、补量建议和折扣集中查看时，唯一允许的附加页为「月度复盘与补量折扣」，并须让正式计划和情景建议分开。记录实际数据截至日期；不得仅因当前日期推断某月已结束。

### 字段和口径

若用户明确要求像「八角围栏销售计划」一样按当前实际差值重排，即使当前月尚未结束，也按用户指定的实际数据截止日做滚动结转：先保留完整月份的原计划比例和原计划目标，再计算实际−原计划差值；当前月未完成量转到后续月。此时不得按剩余自然日压缩当前月原计划比例，也不得把未完成量同时留在当前月快照日后的未来待售量中。若库存快照日期晚于实际销量日期，整期原计划基数用「当前库存快照×目标消化率+快照前实际销量」还原，使实际销量纳入原计划完成度；未来库存消化只检查后续月调整后执行量。

原计划目标必须由月度比例公式可复算。后续月的基础分配仍由各月原销售比例输入和原计划目标计算；「月销量」/月度SKU合计显示增加了按后续原计划比例归一分摊的调整后执行量。明细比例是基础计划权重，不会因追补改变成执行量占比。上方总量标「原计划目标」，合计行标「调整后执行量」，避免二者看似相同。

| 字段 | 含义/规则 |
| --- | --- |
| 原计划销量 | 用户原批准的 SKU 月计划。保留原公式或原输入，不得被实际销量覆盖。 |
| 实际销量 | 同站点、同 SKU、同自然月的实际销量输入/领星来源值，不得为计算方便而改写。 |
| 差值 | `实际销量-原计划销量`，允许正负。实际少于计划时为负，例如计划100、实际60，差值=-40。 |
| 需要分摊量 | `MAX(原计划销量-实际销量,0)`。非负待处理量，不叫「差值」。 |
| 后续月份权重 | 不新增输入。按各未结束月份既有月度目标比例，在剩余月份间计算相对权重。 |
| 调整后计划销量 | 后续月原计划销量加自动分摊量；原计划和实际销量保持不变。仅在原月明细内呈现。用户已确认后续月份「月销量」直接显示调整后执行计划时，必须在备注中清楚标明含前期追补。 |
| 分摊后预计剩余库存 | 当前库存统计的规划总库存，减去快照日后的调整后计划销量。 |

### 计算顺序

1. 锁定每月、每 SKU 原计划公式/值和实际销量来源；先回读确认原计划未被实际数覆盖。原计划已经丢失时，尝试从版本历史、原有公式、先前用户确认内容恢复；仍不能恢复就标「原计划待核实」，不可臆造。
2. 对已结束来源月逐 SKU 计算 `D=max(P-A,0)`；正负差值另算 `V=A-P`。不要把 `D` 放进差值字段。
3. 不询问用户输入新的分摊比例。只列来源月份之后尚未结束的规划月份，按 `目标月权重=目标月原月度比例/SUM(剩余后续月份原月度比例)` 自动算权重。此归一化只用于分摊，不改原月度比例。
4. 对每个 SKU 的未完成量按这些权重计算整数分摊。按最大权重且有承接能力的月份处理舍入残差，不让最后月份/末行无条件承担；同 SKU 的来源月分开追踪，避免重复追回。若剩余后续月份比例合计为0或缺失，标记无法分摊。
5. 目标月追补量合入原表现有月计划量/调整后计划量；原月度目标比例和基础月目标不被静默改写。原SKU明细只增加必要列「需要分摊量」「分摊后预计剩余库存」，不新建专用追补算法表或独立分摊比例输入表。若用户要求月度复盘和折扣同页，可以按本参考后文新增唯一的「月度复盘与补量折扣」sheet。未来月份「月销量」按用户已确认口径直接展示含追补的调整后执行计划；月度SKU合计必须与该执行计划口径一致。基础原计划仍须可从比例/公式还原或保留，不能因显示调整后值而丢失。
6. 逐 SKU、逐目标月检查现有库存口径下的可承接量。若当前库存快照日已扣减过去实际销量，未来库存计算只减去快照日之后的调整后销量，历史实际销量不能再扣一次。库存或销量时间口径不一致时标「待核对」。
7. 若分摊超过 SKU 当前可承接库存，按该 SKU 可承接量限制实际追补；未追回量和原因须清楚提示。不能自动挪到其他 SKU、擅自抬高库存或以其他货号余额抵销。需求或季节性不支持追回时，说明计划风险。

### 公式形态示例

假设某 SKU 10 月原计划为 `P10`、实际销量为 `A10`，11、12、1月既有原计划比例为 `r11`、`r12`、`r01`：

```text
10月差值 = A10-P10
10月未完成量 = MAX(P10-A10,0)
11月权重 = r11/(r11+r12+r01)
12月权重 = r12/(r11+r12+r01)
1月权重 = r01/(r11+r12+r01)
各月分摊量 = 按权重分配需要分摊量，并在库存承接范围内平衡整数余数
11月调整后计划 = 11月原计划+11月前期分摊量
分摊后预计剩余库存 = 当前规划总库存-SUM(快照日后各月调整后计划)
```

按原月度比例求出的权重仅服务于追补，不改变月度目标；余数由有库存承接能力的高权重月份处理。若比例分母为0、库存不足或需求不支持，保留未追回缺口并提示，不能产生超库存结果。分摊只是计划调整，不代表需求已证实。

### 月度合计口径

- 原计划月目标仍为 `ROUND(规划基数*原月度目标比例,0)`。后续月份调整后执行总量为当月各SKU调整后计划之和，因此可能高于原计划月目标。
- 若同一视图要展示原计划目标与调整后执行目标，分别明确标注，不能把追补后的合计仍标作原计划目标，反之亦然。默认保持用户已确认的月度横向布局，不因分摊算法本身另建sheet。若用户要求月度目标/实际复盘、下月补量和折扣集中查看，可另建唯一「月度复盘与补量折扣」sheet；该页只作复盘/情景，不静默改写正式销售计划。
- 折扣场景和销售进度需指出所用基准是原计划还是调整后执行计划；字段名「差值」仍按实际销量−原计划销量，除非表头明确命名为实际−调整后计划。

### 验证要求

- 用临时例子验证：原计划100、实际60时差值为-40、未完成量为40；不得把原计划改成60。
- 以既有后续月份比例示例测试相对权重，例如20%、20%、10%时后续月追补权重为40%、40%、20%；修改原月度进度后追补按新权重动态更新，原比例值不被改写。
- 若后续比例合计为0或缺失，分摊显示无法计算；不得平均分配。
- 改历史实际销量，检查需要分摊量、后续分摊及调整后计划动态变化；确认原明细只增加规定字段，没有专用追补算法表/独立比例输入表；若用户要求月度复盘页，确认仅新增一张复盘与折扣合并sheet。
- 构造库存不足场景，确认未分摊/超限警示出现且没有负期末库存；确认历史实际销量未在当前库存快照上重复扣减。
- 测试完成后恢复临时输入前的原始内容与单元格类型，并回读公式和显示值。

## 3. 月目标、SKU比例、取整与合计

- 标准规则见2A：月总单量来自规划期总计划×当月月目标比例；SKU月销量由该月SKU销售比例驱动。比例是输入，数量是公式结果。
- 所有要求合计100%的比例须逐月核验。比例取整显示为整数百分比；如果显示值无法合计100%，使用可核实的最大余数显示法或提高显示精度，不改写底层计划数量。不能自动归一化用户输入的比例。
- SKU销量必须为整数。按比例取整的差额必须有明确规则并核验SKU库存；无可行分配时显示差额/需调整项。禁止将残差无条件放到末行、跨SKU抵消或静态填入。
- 月合计为当月SKU月销量的SUM；SKU规划期待售总计划为规划月份SUM；期内待售合计为各SKU总计划SUM。不得以静态合计或一个月份残差作为目标输入。
- 修改月目标比例时重新计算月目标和分配；修改SKU某月比例时重新计算该SKU月销量及所有下游公式。若任务明确切换到手动销量模式，则按2A仅限本次，并确认比例不再驱动销量。
- 按SKU/月检查到货日期及库存可承接量。当前库存快照已含过去销售时不重复扣销量。
## 4. 价格、广告与利润

每月每 SKU 使用该月有效售价 `p_i`，优先取销售计划中的月度覆盖价，否则取利润成本表默认售价。有效 TACOS 的覆盖顺序须在表头说明；月度预算若是统一 TACOS，广告费应等于月销售额乘该月 TACOS。

- 月销量 `Q=SUM(q_i)`。
- 加权平均售价 `=IFERROR(SUMPRODUCT(月销量区域,月售价区域)/Q,0)`。
- 月销售额 `R=SUMPRODUCT(月销量区域,月售价区域)`。
- 若所有 SKU 共用月 TACOS `t`：广告花费 `=R*t`。若各 SKU 使用不同有效 `t_i`：广告花费 `=SUMPRODUCT(q_i,p_i,t_i)`，汇总 TACOS `=IFERROR(广告花费/R,0)`。两种口径不要混用。
- 没有实际销量记录的规划月份不增加空白实际销量列。用户不要销售计划明细中的 SKU 级预计利润金额列时，删除各月份对应整列并修复依赖公式；不能仅清空或隐藏。可按用户需要保留顶部预计利润率或折扣情景区，利润率需改由汇总公式计算，不再依赖已删除的明细利润金额列。
- 单件固定成本包括已知的采购、包装、头程、FBA 配送费、固定仓储/退货费等；人民币部分按对应汇率换算成美元。确认合计字段是否已经包括分项，避免重复扣减。
- 未打折预计单件利润 `u_i = p_i - 固定成本_i - p_i*平台佣金率_i - p_i*TACOS_i - 其他已知按售价变化的费用_i - 其他已知固定费用_i`。退货率是否形成费用、形成何种费用，以来源数据的实际定义为准，不凭退货率捏造损失。
- SKU 预计利润率 `=IFERROR(u_i/p_i,0)`；月预计利润 `=SUMPRODUCT(q_i,u_i)`；月预计利润率 `=IFERROR(月预计利润/R,0)`。缺必要成本时保留「待核算」和空白，不以 0 或参考利润率伪装测算结果。

## 5. 折扣情景区

- 「测算月份」只能选择已规划月份。按所选月份和 SKU 取计划销量、实际销量、有效售价及该月原价单件净利；切换月份后各字段同时更新。
- 统一折扣率与单独折扣率限制在 `0%–100%`。单独率空白继承统一率，可用 `=IF(ISBLANK(单独折扣率),统一折扣率,单独折扣率)`；输入 `0%` 必须得到 `0%`，不可用 `IF(单独折扣率,...)` 判断。
- 差值 `=同月实际销量-月计划销量`，允许正负数。实际少于计划时为负数，实际超过计划时为正数。
- 折后预计总利润中的待完成件数用 `=MAX(-差值,0)`；不要在名为「差值」的表头下显示这个非负件数。若界面需要单独显示待完成件数，应明确命名为「待完成量」，并与差值列区分。
- 折后成交价 `p'_i=p_i*(1-生效折扣率)`。有成本拆解时，以 `p'_i` 重算平台佣金、按销售额变化的 TACOS、已知退货损耗及其他变动费用；扣除固定成本与已知优惠工具手续费。所用促销费用假设须标注。
- 仅有可信的原价单件净利、缺少成本拆解时，标「简化测算」，可用 `u'_i≈u_i-p_i*生效折扣率`；不要再重复扣平台佣金或广告费用，也不能称其为精确净利润。
- SKU 折后预计总利润 `=ROUND(MAX(-差值,0)*u'_i,2)`；合计 `=SUM(各SKU折后预计总利润)`。负数红色。该情景计算不能写回正式售价、TACOS、广告预算或后台促销。


### 月度复盘、补量和折扣选择器

- 用户需要持续观察规划期内实际销售时，可在单个「月度复盘与补量折扣」sheet中逐月逐SKU列出：原/参考月目标、实际销量、差值（实际−目标）、待补量（MAX(目标−实际,0)）、次月补量建议、下月原计划、补量后情景销量、当前库存和逐SKU库存超限。差值保留符号，实际少10件必须显示-10；待补量是独立的非负数量。
- 如果目标月的“正常销量”不是原计划已确认值，而是按用户比例、历史/竞品分布或期初库存估算，标题明确叫「参考目标/估算目标」，注明来源、日期、回推方法和期间补货假设；不把估算改写为原计划。未来实际格空白时不计为实际0；月汇总要显示未录入/未录全状态。
- 单月折扣测算控制区必须包含「测算月份」下拉和「折扣比例」下拉。月份选项来自规划期，折扣选项按用户偏好（常见10%、20%、30%、40%）；结果区一次显示一个月的SKU、计划、实际、差值、待补量、售价、对应单件利润和所选折扣利润。切换任一选择后依公式更新。禁止将多个月份的折扣结果并排累计成大表。
- 次月追回按用户给定口径。若用户说下个月补回，默认补量率100%，但补量建议仍是独立情景，除非用户授权，不自动写入正式月销量。任何补量叠加先检查SKU库存和规划期合计；超限显式显示数量及重分配要求。快照库存已反映快照日前销量时不重复扣除实际销量。
- 差值展示必须醒目：差值字段头明确写正负方向及「负数=未达」，使用整数、粗体、浅橙/淡黄区和清楚边框；负数用条件格式标红，正数用另一条件格式标绿。不要颠倒方向，也不能仅靠颜色解释业务含义。
- 若折扣利润基于简化净利，明确公式假设和成本缺口；负利润红色显示。差值、待补量和折扣利润必须是三个可区分概念。

## 6. 销售进度

- 对进行中的月份，以站点自然日计算已过去天数 `E`，含数据日当天、且限制在 `0..该月天数D`；理论进度销量 `=月目标*E/D`。如果销量数据只统计至前一日，则 `E` 也应截至前一日。
- 对已完结月份，理论进度销量就是整月目标；未开始月份或月目标为 0 时显示「未开始/暂无可比」。
- 实际/理论低于可编辑下限（默认 `70%`）显示「明显落后」，高于可编辑上限（默认 `130%`）显示「明显超前」，其余「正常」。阈值是运营提示，不改变实际销量或计划量。

## 7. 飞书回读验证

批量写公式后，分别回读公式文本和实际计算值。检查跨工作表引用、绝对/相对引用、合并格左上角、填充时自动偏移、百分比数值与显示格式。销售分配比例、竞品月度占比和库存消化率用整数百分比显示；需合计100%的比例按最大余数校正并检查显示结果合计100%。预计利润率、TACOS、佣金率、退货率、仓储率等费用/利润率仍保留两位百分比，不能跟着分配比例取整。金额两位小数，汇率及普通数值最多两位，销量/库存整数，日均一位。若百分比数值显示异常，先核对底层值/单位与单元格 number format；不要仅通过格式掩盖错误公式。用独立计算抽查月总量、加权均价、销售额、广告费、利润和库存。临时改一个售价、比例、TACOS、实际销量、统一折扣率、单独折扣率（含空白与 0%）及测算月份，确认依赖结果变化，随后恢复原输入。单月折扣模式还须分别切换至少一个不同月份和不同折扣率，确认结果只显示当前所选月；差值实际低于计划时必须显示负数，并回读条件格式/表头/底色。最后检查无循环引用及 `#REF!`、`#VALUE!`、`#DIV/0!`。

验证销售计划时同时核对：月度比例→月目标公式；每月 SKU 比例之和100%；数量取整后SKU合计与月目标一致；逐 SKU 累计未来量不超库存；实际销量与快照库存时间口径一致。若发现不一致，明确区分公式错误、分配差额和源数据口径冲突，不要把它们都写成「库存通过」。
